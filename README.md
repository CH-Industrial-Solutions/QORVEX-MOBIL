# QORVEX MOBILE · Validación y Secuencia

Versión web publicada en GitHub Pages: https://charliealberth2805-svg.github.io/Qorvex-Mobile/

- Abrir en **Chrome o Edge** en una **tableta o PC con Windows** (Android no permite elegir carpetas).
- La primera vez: **Conectar carpeta** → carpeta compartida **Data Base** y elegir **Este equipo es: TAB1** o **TAB2**.
- Cada tableta escribe solo en sus archivos (`Validacion_TAB1.xlsx` y `Secuencia_TAB1.xlsx`, etc.).
- Este repositorio solo contiene el programa. **Los datos nunca se suben aquí.**
