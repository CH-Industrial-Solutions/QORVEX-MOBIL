# QORVEX MOBILE · Validación y Secuencia (v12)

Publicado en GitHub Pages: https://charliealberth2805-svg.github.io/Qorvex-Mobile/

- Abrir en **Chrome o Edge** en una **tableta o PC con Windows**.
- Primera vez: elegir **TAB1** o **TAB2** → **Seleccionar carpeta** → carpeta compartida **Data Base**.
- Al iniciar sesión se elige el **supervisor** del turno (se puede cambiar en la barra superior).
- Cada captura se agrega al final de `Validacion_TAB1_aaaa-mm.txt` / `Secuencia_TAB1_aaaa-mm.txt` (separado por tabulador).
- **MI TURNO**: mi avance contra la meta del turno, mi ritmo por hora y mis últimos 7 días.
- Turnos, metas, supervisores y usuarios vienen de QORVEX (Motor) → CONFIG.
- Este repositorio solo tiene el programa. **Los datos nunca se suben aquí.**
